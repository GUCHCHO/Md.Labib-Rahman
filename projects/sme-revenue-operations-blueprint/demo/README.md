# Interactive Revenue Operations Dashboard

Open `index.html` in any modern browser. No build tooling, server, framework or network access is required.

## Prototype features
- KPI cards for open pipeline, probability-weighted pipeline, sample closed-won bookings and win rate
- Stage-level weighted-pipeline visualization
- Segment, lead-source and text filters
- Opportunity register with raw and weighted amount
- Responsive layout and clear synthetic-data labeling

## Boundaries
This is a static front-end prototype with embedded synthetic sample data. It does not use an API, persist records, authenticate users, or connect to a CRM, ERP, bank, MFS or payment provider. Do not use it for operational decisions. The architecture and control requirements for production are described in the case-study documentation.
