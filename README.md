## How I Approach a Problem

1. Understand the business goal and baseline the current process.
2. Separate observed facts from reported pain points and assumptions.
3. Map stakeholders, workflows, systems, data ownership and exceptions.
4. Define requirements, acceptance tests and measurable outcomes.
5. Evaluate solution options and integration / security trade-offs.
6. Deliver in phases, monitor adoption and validate impact against a baseline.
